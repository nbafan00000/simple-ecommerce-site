# Northline Goods

A simple React ecommerce demo that shows a paginated product catalog and a mock order flow.

## Features

- Product grid for generic shop goods
- Pagination controls
- Mock checkout modal with quantity and confirmation
- No backend, payment processing, or real order submission

## Run locally

```bash
npm install
npm run dev -- --host 0.0.0.0
```

## Build

```bash
npm run build
```
